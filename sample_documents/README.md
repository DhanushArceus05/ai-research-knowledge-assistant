# Sample Documents

Place your own PDF research papers, whitepapers, or technical documents in this
folder to try out the API locally (via the `/api/v1/documents/upload` endpoint
or the Swagger UI at `/docs`).

No copyrighted research papers are included in this repository. Good free
sources of sample PDFs for testing include:

- [arXiv.org](https://arxiv.org/) — open-access research papers across many domains
- Your own internal technical specifications or reports
- Publicly available government or open-source project documentation

Any PDF with extractable text (not a scanned image) will work well with the
current pipeline.
